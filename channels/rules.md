# 채널별 규칙과 금지 사항

게시 전에 해당 채널 공식 규칙을 다시 확인한다. 아래는 요약이며, 규칙이 바뀌었을 수 있다.

| 채널 | 핵심 규칙 | 우리 운영 |
|---|---|---|
| Hacker News (Show HN) | 사람들이 직접 써볼 수 있는 것만. 투표 요청 금지. 같은 글 반복 게시 금지 | 다운로드 링크와 데모, 한계를 본문에. 10/26 22:00 KST |
| Reddit | 서브레딧마다 자기 홍보 비율·계정 나이·카르마 조건이 다름 | 조건 충족한 곳만, 1시간 간격, 만든 사람임을 밝힘 |
| Lobsters | 초대제. 신규 계정의 자기 홍보에 제약 | 이번 주는 댓글 참여만. 기존 회원이 자기 판단으로 올리는 경우만 |
| GeekNews | 한국어 기술 뉴스. Show GN 형식 | 기술 배경과 한계 중심 |
| Product Hunt | 팔로워 영향 큼 | 7일 이후로 연기 |
| 뉴스레터·awesome 리스트 | 각 제출 양식 | 10/24 일괄 제출, 반영 여부 추적 |

## 공통 금지

- "open source" 표기 (라이선스가 OSI 승인이 아님 → "source-available")
- 출시 전 기능을 현재 기능처럼 표기
- 측정하지 않은 성능 비교 수치
- 자동 게시 봇
